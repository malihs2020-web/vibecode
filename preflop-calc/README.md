# Preflop Push Calc — калькулятор 4-бет пуша

Десктопное приложение (Windows / macOS / Linux). Ситуация: **мы открылись → оппонент 3-бетит → мы пушим олл-ин**.

Вы вводите:
- эффективный стек, наш опен, размер 3-бета и банк перед пушем (всё в bb);
- диапазон 3-бета оппонента;
- диапазон, которым оппонент коллирует пуш.

Калькулятор показывает:
- **минимальное эквити** против диапазона колла, при котором пуш не хуже фолда;
- **плюсовый диапазон пуша**: сетку 13×13 с EV каждой руки и готовой строкой диапазона, которую можно скопировать;
- по каждой руке: фолд-эквити с учётом блокеров, эквити против колла, нужное эквити, EV в bb.

## Как считается

```
EV(пуш) = F · банк + (1 − F) · (эквити · банк_при_колле − наш_довнос)
EV(фолд) = 0
минимальное эквити = (наш_довнос − F/(1−F) · банк) / банк_при_колле
```

- `F` — доля комбинаций 3-бета, которые сбрасывают пуш. Для каждой руки считается с учётом блокеров: с тузом на руках у оппонента меньше AA и AK.
- Коллировать можно только рукой из диапазона 3-бета. Лишние руки колла подсвечиваются и не учитываются.
- Эквити считается методом Монте-Карло в фоне: 60 000 раздач на руку, погрешность около ±0.4%. Руки с EV около нуля (±0.1 bb) между пересчётами могут переходить из плюса в минус и обратно — это пограничные случаи.
- Модель простая: пуш — олл-ин, у оппонента только колл или фолд, эквити реализуется полностью (все деньги в банке до флопа).

## Запуск

Нужен [Node.js](https://nodejs.org) 18+.

```bash
npm install
npm run app        # собрать и открыть окно приложения
npm run dev        # режим разработки в браузере: http://localhost:5173
npm test           # тесты расчётов
```

## Установщик

```bash
npm run dist:win   # Windows: установщик и portable .exe в папке release/
npm run dist:mac   # macOS: .dmg (собирать на Mac)
npm run dist:linux # Linux: AppImage
```

## Устройство

- `src/lib/hands.ts` — карты, 169 классов рук, комбинации, блокеры
- `src/lib/range.ts` — разбор и запись диапазонов (`QQ+, AKs, A5s-A2s, 77-55`)
- `src/lib/evaluator.ts` — оценка силы 7 карт
- `src/lib/equity.ts`, `src/equity.worker.ts` — эквити методом Монте-Карло в фоне
- `src/lib/pushEv.ts` — фолд-эквити, EV, минимальное эквити
- `electron/main.cjs` — окно десктопного приложения

Стек: React + TypeScript + Vite, shadcn/ui (Tailwind), Electron.
