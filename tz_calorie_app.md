# ТЗ на доработки калькулятора калорий

**Контекст:** проект — калькулятор калорий на React + TypeScript + Tailwind + shadcn/ui,
данные в localStorage. Уже реализованы: расчёт нормы калорий, дневник питания,
статистика, база продуктов, светлая/тёмная тема.

Полное ТЗ на новые доработки лежит в tz_calorie_app.md в корне репозитория —
прочитай его целиком перед началом работы.

Реализуй по порядку, тестируя каждый шаг перед переходом к следующему:
1. Логика цели и защитных порогов (раздел "Норма калорий" → "Новое: логика цели...")
2. Расчёт БЖУ через г/кг массы тела с ручным override
3. Граммы как основа учёта + быстрые порции в дневнике
4. Интеграция с Groq API для разбора еды текстом (раздел "Новое: разбор еды текстом")
5. Тот же Groq для авто-заполнения новых продуктов в базе
6. Визуальные напоминания внутри приложения
7. Авто-бэкап JSON раз в день + ручной экспорт/импорт

Прежде чем писать код:
- изучи текущую структуру компонентов и стейт-менеджмент, чтобы новый код
  соответствовал существующим паттернам проекта, а не вводил свои;
- если что-то в ТЗ неоднозначно или противоречит текущей реализации — спроси,
  не додумывай и не выбирай молча.

Ключ Groq уже создан. Переменная окружения — GROQ_API_KEY. Добавь её в .env
(с реальным значением, которое я впишу сам) и в .env.example (с пустым значением,
для коммита в git).
